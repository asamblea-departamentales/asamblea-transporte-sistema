# Sistema de Gestión de Transporte - Asamblea 2026

Este es el repositorio del frontend para el Sistema de Transporte. La aplicación está construida con **React**, **Vite** y **Tailwind CSS**, diseñada como una **PWA** (Progressive Web App) para optimizar el rendimiento y la experiencia de usuario.

## 📖 Documentación

Para instalar este proyecto en una nueva computadora y configurar las dependencias, por favor consulta la guía detallada:

👉 **[GUÍA DE INSTALACIÓN (INSTRUCCIONES.md)](./INSTRUCCIONES.md)**

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

## 🛠️ Tecnologías Principales

- **Framework**: React 19
- **Build Tool**: Vite
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS
- **Estado/Rutas**: React Router Dom
- **PWA**: Vite PWA Plugin
