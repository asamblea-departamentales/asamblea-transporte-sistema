Backend Release Notes

Versión Backend: 2.1.0
Fecha: 20 de Julio, 2026
Entorno: Staging / Production

🎯 Objetivo de esta actualización

Esta versión incluye mejoras integrales en múltiples capas del sistema:

  • Optimización de rendimiento y consultas en Base de Datos
  • Refactorización de arquitectura hacia Capas de Servicio
  • Refuerzo de políticas de seguridad (CORS, Sanctum, CSRF)
  • Procesamiento asíncrono y colas de trabajo
  • Aumento de cobertura con pruebas automatizadas

El objetivo central fue fortalecer el core del backend manteniendo la mayor estabilidad y transparencia frente a las aplicaciones clientes en React.

🚨 Breaking Changes (Cambios Obligatorios)

1. Cambio de Endpoint para Historial de Jefatura

Se reestructuró la ruta de consulta del historial de jefatura dentro del módulo de dashboard. La URL antigua fue deshabilitada.

ANTES GET /api/solicitudes/historial-jefatura
AHORA GET /api/dashboard/historial-jefatura

Nota: La estructura del JSON retornado es exactamente la misma. Únicamente se debe actualizar la constante del path en la capa de servicios de React.

💡 Cambios Recomendados

Perfil del Usuario Autenticado

El endpoint redundante GET /api/user fue removido para estandarizar la API.

USAR GET /api/auth/me

Retorna la misma información y modelo del usuario en sesión.

⚡ Nuevos Endpoints

Health Check Service

GET /api/health

Permite diagnosticar en tiempo real el estado de infraestructura:

  • Disponibilidad de la API
  • Conectividad con la base de datos (MySQL/PostgreSQL)
  • Estado del sistema para monitoreo o alertas de mantenimiento

🛠️ Cambios Internos (Sin Impacto en Frontend)

Se realizaron mejoras técnicas en la arquitectura interna que mejoran la velocidad de respuesta y estabilidad general:

  • Consultas SQL: Solución a problemas de carga diferida N+1 en listados masivos.
  • Validaciones: Migración de validaciones en controladores hacia Form Requests.
  • Desacoplamiento: Abstracción de reglas de negocio hacia Services independientes.
  • Asincronía: Envíos de correos delegados a colas (Queues) para respuestas HTTP inmediatas.
  • Eventos: Trazabilidad del historial de estados impulsado por arquitectura orientada a eventos.
  • Seguridad: Refuerzo en middleware de CORS, manejo de sesiones y respuestas de excepciones centralizadas.
