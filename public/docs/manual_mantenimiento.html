  • Acceso al servidor donde está instalado el sistema

2. Cambiar un nombre en el menú lateral

2.1 Para un Reporte

  1. Abra la carpeta app/Filament/Pages/
  2. Busque el archivo del reporte. Ej: ReporteSolicitudesTransporte.php
  3. Busque la línea: protected static ?string $navigationLabel = 'Reporte de Solicitudes de Transporte';
  4. Cambie el texto entre comillas por el nuevo nombre
  5. Guarde el archivo. El cambio se ve inmediatamente al recargar la página
✍ Ejemplo:

Cambiar 'Reporte de Solicitudes de Transporte' a 'Reporte de Viajes'

  1. Abra la carpeta app/Filament/Resources/
  2. Busque el archivo. Ej: VehiculoResource.php

4. Cambiar el título de una pantalla

El título grande de cada página puede estar definido de dos formas:

// Forma 1: propiedad $title
protected static ?string $title = 'Panel de Control';

// Forma 2: método getTitle()
public function getTitle(): string {
    return 'Reporte de Solicitudes de Transporte';
}

Busque cualquiera de las dos formas en el archivo y cámbiela.

5. Ocultar un elemento del menú (sin borrarlo)

Algunas páginas (Bandeja Operativa, Aprobaciones, Revisión Operativa) existen pero no aparecen en el menú. Se acceden desde otras páginas.

Busque esta línea:

protected static bool $shouldRegisterNavigation = false;

Para ocultar: cámbielo a false. Para mostrar: cámbielo a true o borre la línea.

7. Agregar un reporte nuevo al menú

Paso 1: Crear el archivo PHP del reporte

  1. Vaya a app/Filament/Pages/
  2. Copie un reporte existente (ej: ReporteSolicitudesTransporte.php) con otro nombre, como ReporteControlKilometraje.php
  3. Dentro, cambie: nombre de clase, $navigationLabel, $navigationGroup, $navigationIcon, $navigationSort, $view
⚠ Importante: La vista ($view) usa minúsculas y guiones. Ej: 'filament.pages.reporte-control-kilometraje'

Paso 2: Crear la plantilla visual (Blade)

  1. Vaya a resources/views/filament/pages/
  2. Cree un archivo .blade.php con el nombre que puso en $view
  3. Copie el contenido de otro reporte como base

Paso 3 (opcional): Agregar descarga de PDF

8. Cambiar un PDF descargable

8.1 Cambiar el diseño del PDF

Vaya a resources/views/reports/, busque la plantilla (ej: solicitudes_transporte_pdf.blade.php) y modifique el HTML.

8.2 Cambiar el nombre del archivo

Busque en routes/web.php:

$filename = 'reporte_solicitudes_'.now()->format('Ymd_His').'.pdf';

Cambie el texto 'reporte_solicitudes_'.

8.3 Cambiar orientación del papel

Busque en routes/web.php:

->setPaper('a4', 'landscape')

'landscape' = horizontal, 'portrait' = vertical.

8.4 Cambiar los filtros del PDF

En routes/web.php, las rutas de PDF tienen condiciones:

if ($request->filled('estado')) {
    $q->where('estado', $request->input('estado'));
}

Agregue o elimine bloques if según necesite.

8.5 Cambiar los roles que pueden descargar

abort_unless(auth()->check() && auth()->user()->hasAnyRole([
    'jefe', 'admin', 'ti', 'operativo', 'liquidador', 'super_admin'
]), 403);

Agregue o quite nombres de roles dentro de los corchetes.

10. Agregar o quitar filtros en un reporte

Los filtros se definen en el método form(). Para agregar un filtro nuevo:

  1. Agregue el campo en form(): Select::make('estado')->label('Estado')->options([...])->live()
  2. Agregue una propiedad: public ?string $estado = null;
  3. En buildQuery(): if ($this->estado) { $q->where('estado', $this->estado); }
  4. En getFilterState() agregue el campo para que se envíe al PDF

Para quitar: elimine el campo del formulario, la propiedad, la condición en buildQuery() y la entrada en getFilterState().

11. Cambiar los indicadores (KPIs) de un reporte

Los KPIs se calculan en el método refreshKpis():

private function refreshKpis(): void {
    $base = SolicitudTransporte::query();
    // ... filtros base ...
    $this->kpi_total = (clone $base)->count();
    $this->kpi_pendientes = (clone $base)->whereIn('estado', ['pendiente'])->count();
}

Agregar un KPI nuevo:

  1. Propiedad: public int $kpi_nuevo = 0;
  2. Cálculo en refreshKpis(): $this->kpi_nuevo = (clone $base)->where(...)->count();
  3. Tarjeta en la plantilla Blade

12. Cambiar quién puede ver un reporte o catálogo

// Para Pages (reportes):
public static function canAccess(): bool {
    return auth()->user()?->hasAnyRole([
        'jefe', 'admin', 'ti', 'operativo', 'liquidador', 'super_admin'
    ]) ?? false;
}

// Para Resources (catálogos):
public static function canViewAny(): bool {
    return auth()->user()->hasAnyRole(['admin', 'ti', 'jefe', 'super_admin']);
}

16. Agregar, cambiar o quitar manuales

Agregar un manual nuevo

  1. Coloque el archivo en public/docs/

  4. Guarde y recargue

En el mismo arreglo, cambie el valor de "label".

Quitar un manual

Elimine la línea completa del arreglo $manuales.

Reemplazar un archivo

Sobrescriba el archivo en public/docs/ con el mismo nombre. No necesita cambiar código.

25. Escenarios comunes

📝 Escenario 1: "Cambiar el nombre del reporte de Transporte"

  1. Abra app/Filament/Pages/ReporteSolicitudesTransporte.php
  2. Busque $navigationLabel y cámbielo
  3. Busque getTitle() y cámbielo también
  4. Guarde y recargue

📝 Escenario 2: "Agregar un reporte nuevo (Control de Kilometraje)"

  1. Copie ReporteSolicitudesTransporte.php como ReporteControlKilometraje.php
  2. Cambie: clase, $navigationLabel, $view, $navigationGroup, $navigationIcon
  3. Copie la vista Blade con el nombre que puso en $view
  4. Personalice filtros, columnas y KPIs
  5. Si necesita PDF: cree controlador, ruta y plantilla
  6. Recargue el navegador

📝 Escenario 3: "Cambiar orientación del PDF (vertical/horizontal)"

  1. Abra routes/web.php
  2. Busque ->setPaper('a4', 'landscape')
  3. Cambie 'landscape' por 'portrait' (o viceversa)
  4. Guarde y pruebe descargando el PDF

📝 Escenario 4: "No se ve el cambio que hice"

  1. php artisan cache:clear
  2. php artisan view:clear
  3. Recargue la página (F5)
  4. Si sigue sin verse, limpie la caché del navegador (Ctrl+Shift+Delete)

📝 Escenario 5: "Agregar un manual nuevo al botón de libros"

  1. Coloque el archivo en public/docs/
  2. Abra AdminPanelProvider.php, busque $manuales
  3. Agregue: [ "label" => "Nombre", "file" => "archivo.pdf" ],
  4. Guarde y recargue

📝 Escenario 6: "Quitar un manual del botón de libros"

  1. Abra AdminPanelProvider.php, busque $manuales
  2. Elimine la línea del manual
  3. Guarde y recargue

📝 Escenario 7: "Cambiar el logo del sistema"

  1. Reemplace el archivo en public/images/logo-azul-fondo-transparente.png
  2. O cambie la ruta en AdminPanelProvider.php → ->brandLogo(asset('images/nuevo-logo.png'))
  3. php artisan cache:clear

📝 Escenario 8: "Cambiar el color del sistema"

  1. Abra AdminPanelProvider.php
  2. Busque ->colors(['primary' => Color::Blue])
  3. Cambie Color::Blue por Color::Red, Color::Emerald, Color::Amber, etc.

📝 Escenario 9: "Cambiar el nombre del Dashboard"

  1. Abra app/Filament/Pages/Dashboard.php

  2. Guarde y recargue

📝 Escenario 18: "Cambiar el texto del login"

  1. Abra app/Filament/Pages/Auth/Login.php
  2. Cambie getTitle(), getHeading(), getSubHeading()

📝 Escenario 19: "Cambiar la descripción de la app instalable (PWA)"

  1. Abra config/filament-pwa.php
  2. Cambie 'description', 'name' o 'short_name'

📝 Escenario 20: "Agregar un catálogo nuevo (Tipos de Seguro)"

  1. php artisan make:migration create_tipos_seguro_table
  2. Edite la migración
  3. php artisan migrate
  4. php artisan make:model TipoSeguro
  5. php artisan make:filament-resource TipoSeguro --generate
  6. php artisan shield:generate --all

📝 Escenario 21: "Cambiar los KPIs del reporte de Transporte"

  1. Busque refreshKpis()
  2. Cambie los conteos o agregue nuevos KPIs

📝 Escenario 22: "Corregir un error: la tabla no muestra datos"

  1. php artisan cache:clear
  2. php artisan view:clear
  3. php artisan config:clear
  4. Recargue (F5). Si persiste, revise la consola del navegador (F12)

📝 Escenario 23: "Crear un grupo nuevo en el menú y mover reportes"

  1. En AdminPanelProvider.php, agregue el grupo a ->navigationGroups([...])
  2. En cada reporte, cambie $navigationGroup = 'Nuevo Grupo';

📝 Escenario 24: "Cambiar el nombre del archivo PDF que se descarga"

  1. Abra routes/web.php
  2. Busque la variable $filename y cambie el texto

📝 Escenario 25: "Agregar un botón de exportar CSV al reporte"

  1. Copie el bloque del botón Excel y cámbielo a CSV
  2. Use Excel::download(..., ..., \Maatwebsite\Excel\Excel::CSV)
  3. Si no existe la ruta CSV, créela en routes/web.php

📝 Escenario 26: "Reemplazar el logo por uno nuevo"

  1. Coloque el archivo en public/images/
  2. Cambie la ruta en AdminPanelProvider.php
  3. php artisan cache:clear

28. Glosario

TérminoSignificado
ArtisanLa línea de comandos de Laravel. Todos los comandos empiezan con php artisan
BladeSistema de plantillas de Laravel. Archivos terminan en .blade.php
ClusterGrupo de catálogos en una subcarpeta del menú
ControllerArchivo PHP con la lógica para PDF o acciones
CRUDCreate, Read, Update, Delete — operaciones básicas sobre datos
EndpointDirección web de la API que devuelve JSON
FilamentEl "esqueleto" del sistema que genera menús, formularios y tablas
KPIIndicador numérico en tarjetas arriba de los reportes
MigraciónArchivo que describe cambios en la base de datos
ModeloClase PHP que representa una tabla de la BD
Navigation GroupSección del menú (ej: "Reportes", "Catálogos")
Navigation LabelTexto visible en el menú lateral
PagePantalla completa del sistema (reporte)
PWAProgressive Web App — instalar como app en celular/PC
ResourceListado con formulario CRUD (ej: lista de vehículos)
RouteDirección web definida en routes/web.php o routes/api.php
SchemaArreglo de campos de un formulario en Filament
WidgetTarjeta o componente pequeño en el Dashboard
